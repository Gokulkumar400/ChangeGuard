# Security policy

ChangeGuard is not yet implemented or released. Security reporting and support
procedures are not yet operational.

## Reporting a vulnerability

Do not include sensitive vulnerability details in a public issue. Contact the
project owner through a private channel they have confirmed for security
reports. No security contact address or reporting service is configured in this
repository; none has been invented here.

Before a public release, the project owner should add a verified private
reporting channel and define supported release versions and response
expectations.

## Security scope

The future product is expected to inspect repositories and may invoke test
commands. Its design must treat repository files, configuration, test output,
and commands as untrusted. See `ARCHITECTURE.md` and `TEST_PLAN.md` for planned
security boundaries and validation areas. These are plans, not implemented
protections.
